# wdcloud-Assistant
wdcloud助手

## 安装

在 Harness Desktop 中打开插件页面，添加 https://github.com/yinhexixiaowang/wdcloud-Assistant.git 并启用。

安装并启用后，在 Harness 聊天发送「召唤 wdcloud」。打开回复里的本地激活文件，把原有 wdCloud CDKEY 粘贴到第一行并保存，再发一次「召唤 wdcloud」。验证成功后会显示到期时间并清空文件。请勿在聊天中发送 CDKEY。视频拉片已内置。首次拉片会检测 FFmpeg。Windows x64 缺少 FFmpeg 时会联网下载固定版本、校验并缓存。
