# wdcloud

安装并启用插件后，在 Harness 聊天发送「召唤 wdcloud」。插件会尝试用记事本打开激活文件，未打开时可使用回复中的完整路径，把现有 wdCloud CDKEY 单独粘贴到第一行并保存，再发一次「召唤 wdcloud」。成功后插件会显示到期时间并清空文件。请勿在聊天中发送 CDKEY。已激活用户可在签名租约有效期内断网重启并恢复功能，租约最长 24 小时。视频拉片已内置。首次拉片时会检测 FFmpeg，Windows x64 缺少 FFmpeg 时自动下载并校验。

视频拉片定位：分镜画面 + 字幕大意。不分析语音或光线，不要求精确字幕时间。
